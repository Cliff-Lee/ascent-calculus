01 · THE STARTING POINT

What is an ascent sequence?

It is a sequence whose next value is allowed to grow as upward steps appear.

In this engine’s positive convention, the first value is 1. At each later position, the value is at least 1 and at most 2 + the number of earlier ascents.

VALID EXAMPLElength 5
12rise13rise2
✓1, 2, 1, 3, 2 is an ascent sequence.

Before the final 2, there are two ascents, so the allowed values are 1 through 4.

02 · MARK THE RISES

Each rise has two important positions

Compare neighboring values. The smaller one is the ascent bottom; the larger one is the ascent top.

1bottom2top1bottom3top2

For 1, 2, 1, 3, 2, the engine records ascent tops at positions 1, 2, 4 and ascent bottoms at positions 1, 3. Position 1 is included by convention.

03 · THREE RELATED FAMILIES

Ordinary, modified, and revised

They use related ascent vocabulary, but their definitions are different. The engine checks each rule independently.

A

Ordinary

Starts with 1; each later value is bounded by 2 plus the number of earlier ascents.

M

Modified

A Cayley word where each value’s first occurrence is an ascent top.

R

Revised

A Cayley word where each value’s first occurrence is an ascent bottom.

iThese are precise definitions used by this calculus. Some sequences belong to more than one family; the inspector checks all three.
